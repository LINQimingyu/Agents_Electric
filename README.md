# Agents Electric

Windows 本机电气工程工作台，内置三菱 Q 系列 / GX Works2 离线变更流程。

## 打开工作台

1. 安装 Node.js 24.9 或更高版本。首次安装时保持网络连接，启动器会安装项目自用的 pnpm。
2. 双击 `打开电气工作台.cmd`。启动器准备依赖、安装编排组件并打开浏览器。默认监听 `http://127.0.0.1:3080`，已登录的浏览器也可以打开 `/#electric`。
3. 在「模型设置」配置 DeepSeek API，或添加自定义 OpenAI 兼容端点。新建项目后，在「实施流程」提交变更需求和原始程序 CSV，选择模型并确认资料授权。

命令行入口为 `npm start`，端口可用 `AGENTS_ELECTRIC_PORT` 设置。首次登录时通过启动器进入。退出启动窗口可停止本机服务。

## 工程操作

- 新建项目填写项目名称、CPU 型号、工程工具及版本。流程首节点选择资料文件夹时，会整组读取其中的 CSV（含子文件夹）；单文件上限 5 MB，整组上限 32 MB。Agent 可跨程序段检索，并按相对路径和原始物理行号读取正文。TXT、Markdown 和 Word（DOCX）可读取正文，GXW、PDF 等文件列入清单。放行前须提供变更需求和可读取的程序正文。
- 原件的需求和程序正文齐备后，工程师可填写审批人直接放行，审核说明选填。Agent 的核对建议可展开查看。补资料时沿用同一项目，每次运行绑定对应的需求、资料清单和 CSV。
- Agent 需要确认关键信息时会弹出答复窗口。选择「稍后回答」可以从顶部「待回答」再次打开。答复会回到发问的 Agent，后续节点也能看到本次运行最近的答复。
- 初次启动会创建脱敏示例，要求将状态灯从 `Y0` 改为 `Y1` 并保留门联锁。工作流接受 UTF-8 和带 BOM 的 UTF-16LE CSV。候选生成逐物理行替换，检查原文、分隔符和列数。跨行引用字段或整段插删需先在工程工具中处理。
- 「实施流程」可查看原件、并行节点、待办、差异、运行事件和交接包。重启后在运行记录中打开对应流程并点击「恢复 / 核查」。单次运行窗口为 7 天，含人工待办时间。结果不明的节点由操作者核查后决定结束或重试。
- 多程序段候选按文件和行号生成差异。候选 ZIP 保留原相对路径，包含未修改的程序段。导入当前候选的编译与仿真原始记录，分别登记工具、时间和人工判定。两个验证均通过后进入交付审核。实施、现场接受依次人工登记，工程工具和现场工作在工作台外进行。
- 「工作流模板」支持编辑、复制、保存草稿、发布和绑定 Skill。「添加 Skill」保存为 `SKILL.md`。PLC 模板保留原件确认、方案审核、独立复核、证据和交付等必需依赖。新建通用模板可以自由组合 Agent 和人工审核节点。
- 「PLC 知识库」按设备搜索程序含义、GX Works2 步号和分析来源。通过「工程项目 → 关联设备」启用同设备调用。启动时也可选一个相似设备作参考。每次运行固定知识版本；原始 CSV 摘要变化时，Agent 用本次 CSV 重新定位。
- 新版 PLC 流程正式交付并结束后会生成知识草稿。在知识库对照工程记录和验证证据，编辑并发布选中条目，或驳回整份草稿。暂未关联设备的项目在完成关联后排队。知识库与草稿保存在 `.local/dsh/electric/knowledge.sqlite`。
- 启动 PLC 流程时可选「全链路测试」。候选只允许改注释，结构检查和模拟验收计入测试状态。测试交接包标记「工程未验证」，测试知识草稿可查看和驳回。
- 在「插件管理」打开社区目录，或检查并安装兼容的 npm 包、Git 仓库及本地组合包。安装后可启用、停用和卸载插件。
- 在「Agent 会话」选择模型、发送消息、查看历史及处理待办。工程流程节点可直接打开对应 Agent 会话。开源组件的署名和许可可在「关于 → 开源许可」查看。

## 数据和验证

- 默认 DSH Home 在 `.local/dsh`。电气项目 LLM 会话、配置和插件由 DSH 管理，编排检查点由社区插件管理，工程记录与文件归档在 `.local/dsh/electric`。关停后可备份整个 `.local/dsh`，其中包含模型凭据。`AGENTS_ELECTRIC_HOME` 可指定独立目录。
- `npm test` 检查 CSV 编辑、门禁依赖、候选证据与 ZIP。`npm run test:workbench` 使用 `.qa` 隔离运行环境、Chrome 或 Edge 及本机模拟模型端点。测试不会读取其他 DSH 配置或项目。可用 `ELECTRIC_CHROME` 指定浏览器。
- 外部 API、真实 GX Works2 编译或仿真、现场实施与现场接受须使用实际环境完成验收。
